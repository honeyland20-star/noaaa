# نوا تریدر برای اندروید
پروژه Android Studio، اندروید ۹ یا جدیدتر. در Android Studio با JDK 17 و Gradle 8.9 باز کنید یا گردش Android APK را در یک مخزن GitHub اجرا کنید. خروجی assembleDebug برای نصب آزمایشی است. برای توزیع پایدار نسخه release را با کلید خود امضا کنید.

در تنظیمات، بازار، خرید یا فروش، مبلغ و قیمت هدف را مشخص و ذخیره کنید. برای گزارش تلگرام، در BotFather ربات بسازید، گفت‌وگو با آن را شروع کنید و شناسه عددی همان چت و توکن را وارد کنید. آزمایش تلگرام یک پیام واقعی می‌فرستد. ساخت کلید و اعطای مجوز نوبیتکس در پنل خود صرافی انجام می‌شود. رمز حساب صرافی لازم نیست. ارتباط مستقیم گوشی با نوبیتکس به IP ایران و ارتباط با دو سرویس دیگر به دسترسی شبکه نیاز دارد.

پایش با برنامه باز کار می‌کند، حدود هر دقیقه بررسی می‌کند و برای هر بار فعال‌سازی فقط یک سفارش می‌فرستد. پس از بازشدن مجدد برنامه، پایش قبلی از سر گرفته نمی‌شود. سفارش باز در صرافی می‌ماند. لغو سفارش باز از پنل نوبیتکس انجام می‌شود. اگر پاسخ ثبت سفارش قطع شود، برنامه به طور خودکار سفارش دیگری نمی‌فرستد. برای تطبیق دستی شناسه سفارش نوبیتکس لازم است. در صورت رد قطعی سفارش بدون شناسه، وضعیت نامشخص ممکن است نیازمند بررسی و بازیابی دستی باشد.

سرمایه آزمایشی اولیه ۱۰۰۰ تتر است. تنظیمات و تاریخچه با Android Keystore محافظت می‌شوند. حالت واقعی ابتدا خاموش است. برای استفاده واقعی کلید READ و TRADE و بدون مجوز برداشت لازم است. کلیدها را در مخزن قرار ندهید.

فیلتر خبر از تیترهای انگلیسی Google News RSS و کلمات حساس استفاده می‌کند. این مدل پیش‌بینی یا اعتبارسنجی مستقل منبع نیست. داده ناقص، نبود خبر، نقدشوندگی کم و فاصله قیمت زیاد جلوی سفارش را می‌گیرند. مانع خبر حساس فقط روی خرید اعمال می‌شود. نتیجه مالی ارزیابی نشده است.
